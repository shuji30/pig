# アバターを Blender でモデリングする

> **いまの本線は VRoid Studio です。→ [`tools/vroid/README.md`](../vroid/README.md)**
>
> ここのスクリプトは基本形（球・円柱・張った面）を組み上げるもので、
> どれだけ調整しても「基本形の寄せ集め」に見え、人が彫ったモデルには届きません。
> 本線は VRoid Studio で作った `.vrm` を `public/avatar.vrm` に置く方式に移しました。
>
> このスクリプトは残してあります。役目は次のふたつです。
>
> - **寸法の決めごと**（5頭身・目の高さ 39.6px・ボーン名）を、動く形で残すため
> - `.vrm` を置いていないときに出る、基本形のアバターと同じ考えかたの見本

| | |
| --- | --- |
| `avatar_model.py` | **ひととおり組み上がったアバター**を作り、`out/avatar.glb` に書き出す |
| `avatar_blockout.py` | 当たりとボーンだけ。**自分でモデリングする**ときの下地 |

どちらも寸法・向き・ボーン名は同じです。作り込みたいときは `avatar_blockout.py` の
当たりの上から作り、そのまま置き換えられます。

## `avatar_model.py`（組み上がったもの）

```
blender --background --python tools/blender/avatar_model.py
```

家具（`src/render/models3d.js`）と同じで、**角を丸めた基本形を組んでなめらかにする**
作りです。この箱庭はその質感で通っているので、キャラクターだけ作り込んでも浮きます。

- 体・顔（目・ひとみ・口）・髪（ボブ）・ふく・くつ
- ボーンへの結びつけは**部位ごとに丸ごと1本**（リジッド）。平らな絵も紙人形なので、
  曲げないほうが絵と合います
- マテリアルは `skin / hair / eyes / shirt / pants / shoes` の6つ（＋白目・口）。
  ゲーム側はこの名前を見て、きせかえの色に差し替えます

いまの出力は **26,000三角・927KB**。VR では最大3体まで並ぶので、実機で重ければ
面を減らすか Draco 圧縮をかけます。

## `avatar_blockout.py`（下地だけ）

`avatar_blockout.py` は、**寸法の合った当たり（ブロックアウト）とボーン**を Blender の中に
作るだけのスクリプトです。この上からモデリングすれば、できたモデルがゲームの中で
今までと同じ大きさ・同じ目の高さになります。

```
Blender で開く: Scripting タブ → 開く → avatar_blockout.py → 実行
コマンドから  : blender --background --python tools/blender/avatar_blockout.py
```

当たりは**ワイヤー表示・選択不可・レンダリングしない**ので、そのまま上に置いて作業できます。
じゃまなら `blockout` コレクションごと隠してください。

## 守ってほしいこと

ここを外すとゲーム側で合いません。

| | |
| --- | --- |
| 単位 | **1 Blender 単位 = 1m**。足のうらが `z = 0` |
| 向き | **-Y を向く**。Blender の正面図（テンキー1）がそのまま前 |
| ボーン名 | スクリプトが作る 20 本の名前をそのまま使う |
| 書き出し | **glTF 2.0 (.glb)**。「+Y Up」は既定のままでよい |

向きの理屈: glTF に書き出すと Blender の -Y が +Z になり、ゲーム側の「体の正面は +z」と
一致します（`src/vr/avatar3d.ts`）。書き出した .glb で目の位置が
`y = 1.0105 / z = +0.29` になっていれば合っています。

## 寸法（立ち姿）

もとは平らな絵（`src/render/avatarArt.ts`）です。**1m = 39.19px**
（`src/render/models3d.js` の `PX_PER_HEIGHT`）で換算しています。

| | px | m |
| --- | ---: | ---: |
| 頭のてっぺん（身長） | 55.4 | **1.414** |
| 頭の中心 | 42.0 | 1.072 |
| **目**（VR のカメラがここに入る） | 39.6 | **1.010** |
| 胴の上 | 29.0 | 0.740 |
| 肩 | 27.0 | 0.689 |
| 手 | 17.0 | 0.434 |
| こし | 14.0 | 0.357 |
| くつの上 | 6.0 | 0.153 |
| 頭の半径 | 13.4 | 0.342 |
| 胴の幅 | 17.0 | 0.434 |
| 腕の中心（左右） | ±9.9 | ±0.253 |
| 脚の中心（左右） | ±4.7 | ±0.120 |

頭が身長の **27%** というチビ体型です。目が 1.01m なのはそのためで、家具（座面 0.51m /
テーブル 0.77m）に対しては小さめに立ちます。**この比率は変えないでください** —
変えると等角の画面と別人になります。

## ボーン（20本）

```
root
└ hips
  ├ spine ─ chest ─ neck ─ head
  │         ├ shoulder.L ─ upperarm.L ─ forearm.L ─ hand.L
  │         └ shoulder.R ─ upperarm.R ─ forearm.R ─ hand.R
  ├ thigh.L ─ shin.L ─ foot.L
  └ thigh.R ─ shin.R ─ foot.R
```

ゲーム側はこのうち `hips / spine / chest / head / upperarm.* / forearm.* / thigh.* / shin.*`
を動かします。残りは形を保つためのものです。

## 作るもの

まず**1体だけ**（既定の髪型・シャツ・表情なし）で見比べるのがおすすめです。
全部そろえるなら、**髪型は10種・ふくは4種を別メッシュ**にしてください。
色（肌・髪・瞳・服・ズボン・靴）はマテリアルを分けておけば、ゲーム側で差し替えます。

## まだ無いもの

- **髪型は1種（ボブ）だけ**。残り9種は別メッシュとして足す
- **ふくは1種（シャツ）だけ**。ワンピース・パーカー・セーラーが要る
- **表情が無い**。7種＋まばたきはシェイプキーで入れる

## ゲームに繋ぐ

`.glb` をゲーム側で読むには、`GLTFLoader.js` と、それが使う
`BufferGeometryUtils.js` / `SkeletonUtils.js` を `vendor/three/addons/` に足す必要が
あります（`npm run vendor` の一覧に追記）。

読み込みと、`AvatarPose`（歩きの振り・呼吸・16種のモーション）をボーンに繋ぐところは
まだ書いていません。いまの `src/vr/avatar3d.ts`（基本形を組み立てる実装）を
差し替える形になります。
