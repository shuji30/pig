# VRoid Studio でアバターを作る

立体のアバターを、球や円柱を積んで作るのはやめた（`tools/blender/` 参照）。
どれだけ調整しても基本形の寄せ集めに見え、人が彫ったモデルには届かない。
**VRoid Studio で作って VRM で書き出し、ゲームはそれを読む**。

- VRoid Studio: <https://vroid.com/studio>（無料 / Windows・Mac）
- 出てくる `.vrm` は glTF なので、three.js がそのまま読める
- ボーン名が規格で決まっているので、ゲームの姿勢をそのまま流しこめる

置き場所はここ **1か所**だけ:

    public/avatar.vrm

置いていなければ、今までどおり基本形のアバターが出る（ゲームは止まらない）。

---

## 1. 作る

VRoid Studio で新規作成 → 顔・髪・体・衣装を作る。ふつうに作ってよいが、
このゲームで効くところだけ挙げる。

| 項目 | どうするか | なぜ |
|---|---|---|
| 身長 | **気にしなくてよい** | 読みこむとき、目の高さが 39.6px（≒1.01m）に来るよう自動で縮める。部屋も家具もその背丈で作ってある |
| 髪 | 揺れもの（スプリングボーン）は付けてよい | VR で歩くと自然に揺れる。こちらで毎フレーム更新している |
| 衣装 | **明るい色・白っぽい色**にしておく | きせかえの色を **掛け算** で乗せる。元が濃いと色が変わらない |
| 肌 | 既定のままでよい | 同上。きせかえの肌色が掛かる |
| 表情 | プリセット（`happy` `sad` `angry` `relaxed` `surprised` `blink`）を残す | ゲームの7表情をここへ割りあてている |
| 瞳・口 | 色は自由 | きせかえの対象外。さわらない |

## 2. 書き出す

「撮影・エクスポート」→「エクスポート」→ VRM。設定は次のとおり。

| 設定 | 値 | なぜ |
|---|---|---|
| ポリゴン削減 | **有効**（既定のまま） | Quest / スマホでも動かしたい |
| ボーン数削減 | 有効 | 揺れものを間引く。見た目はほぼ変わらない |
| マテリアル数削減 | **有効** | 描画回数が減る。VR は 90fps 出したい |
| テクスチャアトラス | **1024** か 2048 | 4096 だと配信が重い |
| VRM 形式 | 1.0 でも 0.x でもよい | どちらも読める |

書き出したファイルを `public/avatar.vrm` に置いて、**コミットする**。
GitHub Pages は リポジトリの中身をそのまま配るので、置いただけだと
手もとでしか出ない。

### 大きさの目安

**8MB 以下**に収めたい。超えるならテクスチャアトラスを 1024 に落とす。
GitHub Pages から配るので、初回に落ちてくる量がそのまま待ち時間になる。

なお `.vrm` は Service Worker の先読み一覧（`src/pwa/precache.ts`）には
**入れていない**。VR に入ったときに初めて取りにいく。

## 3. 確かめる

    npm run dev

ブラウザで開いて VR ボタン。鏡の前に立つと自分のすがたが映る。

- 出ない → ブラウザの Network タブで `avatar.vrm` が 200 で返っているか
- カメラが胸のあたりにある → 目の位置が VRM に入っていない。VRoid の
  書き出しなら必ず入っているので、別のツールで作ったファイルを疑う
- きせかえの色が変わらない → 衣装の色が濃すぎる。掛け算なので、
  黒い服には何を掛けても黒いまま

## いまできていないこと

**髪型10種・ふく4種の切り替えは、VR では効かない。**
VRM 1ファイルには髪型もふくも1種類しか入らないため。
色（肌・髪・シャツ・ズボン・くつ）は掛け算で効く。

増やすなら、いまのところ次のどちらか。

1. 髪型・ふくごとに VRM を書き出し、`avatar-hair3-dress.vrm` のように
   並べて、きせかえに合わせて読みかえる。配信量は増える
2. 素体は同じまま、髪と衣装のメッシュだけを別 VRM から抜いて差し替える。
   VRoid の同じ素体から書き出したファイルはボーンがそろうので、
   `SkinnedMesh` の付けかえで足りる。1ファイルあたりの追加は小さい

どちらも作りは決まっているので、必要になったら足す。

## ゲーム側のつくり

| ファイル | 役目 |
|---|---|
| `src/vr/vrmSource.ts` | `public/avatar.vrm` を1回だけ取ってくる。無ければ `null` |
| `src/vr/vrmPose.ts` | 紙人形の姿勢 → 人型ボーンの角度。three を読まないので単体で試せる |
| `src/vr/vrmAvatar.ts` | VRM 1体。背丈合わせ・色・表情・一人称の頭隠し |
| `src/vr/avatar3d.ts` | 外向きの顔。VRM が来たら基本形と入れかえる |

紙人形の姿勢（位置で作る）を関節の角度に読みかえるところが要。
厳密には一致しないので、「立ち・歩き・すわり・手を上げる」の4つが
平らな絵と同じに**見える**ところへ係数を寄せてある（`vrmPose.ts`）。
